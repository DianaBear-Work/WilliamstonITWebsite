SELF-SERVICE HELP

Troubleshooting

Start with these basic checks. If the issue continues, submit a ticket with the error message and details.

Security reminder: Never share your password or MFA verification code. Use approved company processes for account recovery.
01

Sign-in or Okta issues

  • Check your username and confirm there are no typing errors.
  • Confirm your device has an approved network connection.
  • Write down the exact error message and application name.
  • Use the approved recovery process; never share your password or MFA code.
Account help guide →
02

Laptop or application problems

  • Save your work and close and reopen the affected application.
  • Restart your laptop if practical and permitted.
  • Note whether the problem affects one application or the entire device.
  • Include your device name, the time of the issue, and any error message in the ticket.
Laptop help guide →
03

Printer or connectivity issues

  • Check whether the device is powered on and connected.
  • Confirm that you selected the correct printer or network.
  • Check whether nearby coworkers are experiencing the same issue.
  • Include the printer name or location and when the problem began.
Printing guide →
04

Requesting application access

  • Submit the required access request through the approved company process.
  • Include the application name and business justification.
  • Ask your manager to approve the request when required.
  • Do not use another employee's account to work around missing access.
