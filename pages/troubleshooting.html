SELF-SERVICE HELP

Troubleshooting

Try these basic checks for common issues. If the issue continues, submit an IT ticket and include any error messages.

Security reminder: Never share your password or MFA verification code with anyone. Follow Vertiv-approved processes for account recovery and access requests.
01

Sign-in or account issue

  • Confirm your username and check for typing errors.
  • Check that your device is connected to the company network or approved connection.
  • Record the exact error message and the application you were trying to access.
  • Use the approved account recovery process. Do not share passwords or MFA codes.
Account help guide Add link →
02

Laptop or application problem

  • Save your work, then close and reopen the affected application.
  • Restart the laptop if practical and permitted.
  • Note whether the issue affects one application or the whole device.
  • Include the device name, time of issue, and any error message in your ticket.
Laptop help guide Add link →
03

Printer or connectivity issue

  • Check whether the printer or network connection appears powered and connected.
  • Confirm the correct printer or network is selected.
  • Note whether nearby coworkers are experiencing the same problem.
  • Submit a ticket with the printer name or location and the time the issue started.
Printing guide Add link →
04

Requesting application access

  • Submit the required access request through the approved company process.
  • Include the application name, business justification, and required role if known.
  • Ask your manager to approve the request when required.
  • Do not use another employee's account to work around missing access.
